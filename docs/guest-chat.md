# 对话记账游客界面

`/ledger` 和 `/ledger/chat` 允许游客直接进入，显示独立的三轮剩余额度。第三轮回复完整保留；耗尽时保留历史和当前输入，提供返回 `/ledger/chat` 的登录和注册链接。正式确认入账继续要求登录。

输入草稿按后端身份隔离。文字及选中图片编号存于各标签页的 `sessionStorage`，图片文件以独立随机编号存于 IndexedDB。刷新、焦点验证及完整页面登录后可恢复；只有后端验证的 `adoptedGuestKey` 可以接续游客输入，账号已有未发送输入优先保留。退出、切换账号或身份验证失败时隐藏原账号内容。

复制标签页可能继承输入和图片编号，因此修改或发送只清理当前标签页的引用，不删除另一页仍可能使用的图片。浏览器清除站点数据会清理图片缓存；目前没有自动回收无引用图片的任务。

验证命令：

- `npm run build`：生产构建通过，保留现有地图配置。
- `npx playwright test --config=playwright.chat.config.ts`：桌面和手机共 26 项通过，包括三轮、刷新、登录接续、退出隔离、旧草稿编辑、独立标签页及复制标签页图片隔离。
- `npx playwright test --config=playwright.account.config.ts`：原统一账号流程共 12 项通过。

上线后用公开 HTTPS 入口验证三个功能各三轮、第四次拒绝、刷新额度不变，以及桌面和手机入口、登录注册链接和页面资源。
